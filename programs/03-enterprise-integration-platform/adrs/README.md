Este catálogo registra as decisões estruturantes do Programa 03 aceitas pelo Architecture Review Board. Os ADRs preservam contexto, decisão, alternativas, consequências e critérios de revisão, constituindo a fonte de verdade para implementação e conformidade.

- decisões aceitas são normativas para a Release 1.0;
- substituição exige novo ADR e referência ao registro sucedido;
- exceções são tratadas pelo framework de governança do programa;
- revisões preservam histórico e consequências conhecidas.
