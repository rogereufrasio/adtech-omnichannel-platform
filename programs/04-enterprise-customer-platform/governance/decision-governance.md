## Executive Summary

Decisões são registradas, rastreáveis e revisadas quando premissas mudam.

## Classes de Decisão

| Classe | Autoridade |
| --- | --- |
| Produto local dentro de guardrails | Product/Architecture Owner |
| Contrato compartilhado | Domain Owners afetados |
| Padrão transversal | Architecture Review Board |
| Privacidade e risco crítico | Privacy/Risk Authority |
| Exceção de baseline | Architecture Review Board |

## Ciclo

Propor → analisar contexto e opções → decidir → registrar ADR → comunicar → verificar consequências → revisar gatilhos.

## Controles Obrigatórios

Owner, evidência, métrica, risco e ciclo de revisão são obrigatórios. Exceções possuem controle compensatório e validade.
